# Audio Capture 2.2.0 for Windows

Transcribe one completed English MP4 offline through the Windows interface, JSON CLI, or stdio MCP. All three use the same Rust worker and save plain text and timed JSON.

## Install

1. Download `AudioCapture-Rust-Windows-x64.zip` and `SHA256SUMS.txt`.
2. Download `AudioCapture-Whisper-base.en-model.zip` if you want offline MP4 transcription.
3. Verify each ZIP against the matching filename in `SHA256SUMS.txt`.
4. Extract the app ZIP. Run `audio-capture.exe`.

Keep `transcribe.exe` beside `audio-capture.exe`. The app runs on Windows 11 x64. [Checksum commands](https://github.com/scubamount/AudioCapture/blob/v2.2.0/README.md#verify-the-downloads)

## Transcribe locally

1. Extract the model ZIP into a separate folder.
2. Open **Transcribe files…**.
3. Set **Model pack folder** to the extracted model folder.
4. Select **Import base.en pack**.
5. Choose your MP4. Select the output folder.
6. Preview the job. Approve it to start work.
7. Read the timed transcript in the app or open the saved text and JSON.

The worker decodes the first audio track through Windows Media Foundation and runs Whisper `base.en` on your CPU. Audio stays on your computer. [Offline MP4 guide](https://github.com/scubamount/AudioCapture/blob/v2.2.0/rust/README.md#transcribe-an-mp4-offline)

## Changes since 2.1.0

- Preview, approve, cancel, and review local MP4 jobs in the Windows interface. Batch actions launched there run without a visible console.
- Use `audio-capture.exe control` for the headless JSON CLI or `audio-capture.exe mcp` for stdio MCP. A scoped grant limits each client to approved inputs and outputs. [Agent configuration](https://github.com/scubamount/AudioCapture/blob/v2.2.0/rust/README.md#control-a-local-mp4-job)
- Choose **Use an endpoint…** for endpoint-based file batches. The app shows the service options and asks for approval before transfer. [Endpoint workflow](https://github.com/scubamount/AudioCapture/blob/v2.2.0/rust/README.md#use-an-endpoint-for-completed-files)
- Keep using your compatible endpoint for live transcription. Speaker attribution and memory export are available as separate workflows. [Live transcription](https://github.com/scubamount/AudioCapture/blob/v2.2.0/docs/live-transcription.md) · [Speaker workflow](https://github.com/scubamount/AudioCapture/blob/v2.2.0/docs/speaker-workflow.md)

## Verification

The UI, CLI, and MCP produced identical text and timed JSON from one 5-minute 49-second English MP4. Three CPU runs took 119 to 154 seconds. The Windows UI test ran on an isolated desktop and observed zero visible console windows. [Benchmark method](https://github.com/scubamount/AudioCapture/blob/v2.2.0/docs/performance.md#offline-mp4-transcription)
