# Audio Capture 2.1.0 for Windows

Record and transcribe independently. Use the same endpoint, model, and timestamp settings for live audio and completed files.

## Install and configure

1. Download `AudioCapture-Rust-Windows-x64.zip` and `SHA256SUMS.txt`.
2. Compare the ZIP's SHA-256 with the checksum file before extraction.
3. Extract the ZIP. Copy `config/transcription.example.json` to `transcription.json` beside `audio-capture.exe`.
4. Set your endpoint, model, and transcript folder. If your service needs a key, enter its environment variable name.
5. Open the recorder. Select **Start transcription** for live audio or **Transcribe files…** for saved recordings.

You can also use **Transcription settings → Load config…** to open an existing profile. Review the inputs and destination before approving a transfer.

## Changes since 2.0.0

- Start or stop recording and transcription separately. Read the partial transcript during a call and keep the final text on stop.
- Inspect either settings panel while both activities run. The panel scrolls into view and keeps active settings locked.
- Reuse recent programs and queue completed recordings for batch transcription.
