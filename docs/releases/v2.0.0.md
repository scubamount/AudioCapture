# Audio Capture 2.0.0 for Windows

Record a Windows program and your microphone on separate tracks. Transcribe finished recordings when you choose. This release brings the Rust recorder to the fork's default branch.

## Install

Download `AudioCapture-Rust-Windows-x64.zip` for Windows 11 x64. Extract it, keep the files together, and run `audio-capture.exe`. The ZIP includes the transcription worker, an optional speaker adapter script, and dependency notices.

To verify the download, compare the result of this command with the entry in `SHA256SUMS.txt`.

```powershell
(Get-FileHash .\AudioCapture-Rust-Windows-x64.zip -Algorithm SHA256).Hash
```

## Recording and transcription

- Select a program, a microphone, or system audio. Save separate tracks, a combined mix, or both.
- New settings use regular Opus at 32 kbps mono. Six recording profiles include two speech DTX options for smaller files during pauses.
- Select the WAV sample rate or Opus bitrate in the recorder. Saved settings take precedence over the first-launch profile.
- Transcribe one recording or a batch through a compatible endpoint. Recording starts no transcription jobs.
- Run speaker analysis after recording. Use an optional local model or a supported diarized transcription response.
- Review names suggested from introductions and conversational evidence. Approve a versioned JSONL export when you want to send reviewed turns to a memory pipeline.

The portable download excludes model weights and FFmpeg. See the [recording and transcription guide](https://github.com/scubamount/AudioCapture/blob/v2.0.0/rust/README.md) for optional tool setup.

## Benchmark results

On two tracks from one 29.088-second call, 32 kbps speech DTX used 69,173 bytes. Regular 32 kbps Opus used 157,593 bytes. The transcripts differed after re-encoding.

Across 24 synthetic calls, TitaNet speaker attribution measured 7.66% diarization error on separate tracks and 21.38% on a single mix. The test supplied reference text and timing.

See the [charts, methods, and limits](https://github.com/scubamount/AudioCapture/blob/v2.0.0/docs/performance.md) for the storage, speaker attribution, and automatic naming results.
